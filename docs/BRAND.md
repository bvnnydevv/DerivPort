# DerivPort mark

The mark is a mint **D** with a rising, smooth derivative curve inside its counter. Its simple outline connects the product's name with calculus and stock research. It contains no text, emoji, external resources or scripts.

## Figma source

- File: [Hackathon — DerivPort](https://www.figma.com/design/ZxLybASxv0lxyUkdnQ33A2/Hackathon-DerivPort).
- New page: **Brand**, page `8:2`.
- Native component: [DerivPort / Mark](https://www.figma.com/design/ZxLybASxv0lxyUkdnQ33A2/Hackathon-DerivPort?node-id=8-8), node `8:8`.

The vector geometry was imported into the user's own Figma browser session as editable paths, converted to a reusable Figma component, and exported through Figma's SVG export control. Existing Research, Algorithm builder and Reference screens were left unchanged. The separate MCP connector account was not used to edit this file.
